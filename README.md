## 7. Об'єктно-орієнтоване програмування

Створено систему управління університетом.

Основні класи:

| Клас | Призначення |
|---|---|
| Student | Інформація про студента та його успішність |
| Course | Навчальні дисципліни |
| Person | Абстрактний базовий клас |
| Professor | Інформація про викладача |
| University | Управління студентами, викладачами та курсами |

Реалізовано успадкування, перевизначення методів, додавання та видалення студентів, пошук, оновлення оцінок, перевірку передумов зарахування та формування статистики.

### Приклад використання

```dart
import 'package:dart_basics_vivchar/models/student.dart';
import 'package:dart_basics_vivchar/models/university.dart';

void main() {
  final university = University(name: 'ISTU');

  final student = Student(
    id: 'S001',
    firstName: 'Test',
    lastName: 'Student',
    birthDate: DateTime(2005, 1, 1),
  );

  university.addStudent(student);
  student.enrollInCourse('C001');
  student.addGrade('C001', 95);

  print(student.gpa);
}
```

## 10. Тестування та якість коду

Для перевірки проєкту використано:

```bash
dart format bin lib test
dart analyze
dart test
```

| Перевірка | Результат |
|---|---|
| Запуск програм | 5/5 |
| Автоматичні тести | 19/19 |
| Аналізатор коду | No issues found |
| Звіт про покриття | Сформовано |

### Формування звіту про покриття

```bash
dart test --coverage=coverage
dart run coverage:format_coverage --lcov --in=coverage --out=reports/lcov.info --report-on=lib
```
